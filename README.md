# ربات مدیریت گروه تلگرام (نسخه مهندسی شده)

این ربات برای کمک به مدیریت گروه‌های تلگرام با ارائه قابلیت‌هایی مانند فیلتر کردن پیام‌ها،
مدیریت کاربران و سیستم ضد سیلاب طراحی شده است.

## پیش‌نیازها

- Python 3.9 یا بالاتر
- pip (مدیریت بسته پایتون)
- (اختیاری) PostgreSQL برای محیط پروداکشن
- (اختیاری) Redis برای سیستم ضد سیلاب پیشرفته‌تر

## راه‌اندازی

1.  کلون کردن مخزن (در صورت وجود):

    ```bash
    git clone <repository_url>
    cd telegram_group_manager_bot
    ```

2.  ایجاد و فعال‌سازی محیط مجازی (توصیه می‌شود):

    ```bash
    python -m venv venv
    source venv/bin/activate  # در لینوکس/مک
    # venv\Scriptsctivate    # در ویندوز
    ```

3.  نصب وابستگی‌ها:

    ```bash
    pip install -r requirements.txt
    ```

4.  تنظیم متغیرهای محیطی:
    فایل `.env.example` را به `.env` کپی کرده و مقادیر آن را با اطلاعات واقعی خود پر کنید:

    ```bash
    cp .env.example .env
    nano .env  # یا ویرایشگر دلخواه شما
    ```
    مقادیر ضروری:
    - `BOT_TOKEN`: توکن ربات شما که از BotFather دریافت کرده‌اید.
    - `DATABASE_URL`: آدرس اتصال به پایگاه داده. برای شروع، SQLite مناسب است.
    - `OWNER_IDS`: شناسه‌های عددی تلگرام مدیران اصلی ربات (جدا شده با کاما).

5.  اجرای ربات:

    ```bash
    python main.py
    ```

## افزودن ربات به گروه

1.  ربات خود را در تلگرام با نام کاربری که برای آن انتخاب کرده‌اید جستجو کنید.
2.  آن را به گروه مورد نظر خود اضافه کنید.
3.  **بسیار مهم:** ربات را به عنوان **مدیر (Admin)** در گروه خود انتخاب کنید و مجوزهای لازم مانند "حذف پیام‌ها" (Delete messages)، "مسدود کردن کاربران" (Ban users) و "محدود کردن کاربران" (Restrict users) را به آن بدهید. بدون این مجوزها، ربات قادر به انجام وظایف مدیریتی خود نخواهد بود.
